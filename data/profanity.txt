# ============================================================
# KÜFÜR / HAKARET KÖK LİSTESİ
# Bu dosyayı serbestçe düzenleyebilirsin. Program her çalıştığında
# yeniden okur. Satır formatı:
#
#     kök | bayrak, bayrak, ...
#
# Bayraklar:
#   strong     : Açık ve net küfür/hakaret (VARSAYILAN). Tek başına HIGH.
#   mild       : Hafif hakaret. Tek başına SUSPECT; hedef isimle birlikte HIGH.
#   ambiguous  : Belirsiz, sevinç/şaka olabilir. Tek başına SUSPECT.
#   exact      : Sadece tam kelime olarak eşleşir (kelime içinde geçerse sayılmaz).
#   keep_i     : ı/i harfleri ayrı tutulur ("sıkıntı" ile "sikinti" karışmasın).
#
# Notlar:
#   - Küçük/büyük harf, Türkçe karakter, tekrar eden harfler ("amkkk"),
#     araya konan nokta/yıldız ("a.m.k", "s*k") ve rakamlar ("s1k")
#     program tarafından otomatik olarak normalize edilir. Burada
#     kökleri normal yazımıyla yazman yeterli.
#   - Birden fazla kelimeden oluşan kökler ("amına koyayım") boşluklar
#     silinerek aranır.
#   - Yanlış pozitif olursa: ya köke "exact"/"keep_i" ekle ya da masum
#     kelimeyi data/allowlist_words.txt dosyasına yaz.
# ============================================================
